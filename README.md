## 🛠️ Key Featured Projects

* **[Nigehban — Real-Time Crime Monitoring Platform](https://github.com/ALI22ASHAR/Nigehban)**  
  Full-stack crime intelligence platform tracking 4,200+ FIR records, 364 officers, and 36 police stations. Powered by async FastAPI, SQLAlchemy 2.0, PostgreSQL, 8s WebSocket incident streaming, and React 19 + Leaflet.

* **[Investigation Intelligence Platform](https://github.com/ALI22ASHAR/Investigation-Intelligence-Platform)**  
  Sovereign RAG platform parsing unstructured legal dossiers and evidence records. Automated OCR ingestion (Tesseract), ChromaDB dense vector indexing, and local LLM reasoning with cited source grounding.

* **[Metric-Mind — AI Business Intelligence Platform](https://github.com/ALI22ASHAR/Metric-Mind)**  
  Production-grade BI engine pairing deterministic DuckDB and Polars aggregations with LLM reasoning to achieve zero numerical hallucinations.

* **[Bizionary — AI-Enabled ERP System for SMEs](https://github.com/ALI22ASHAR/FYP-Bizionary)**  
  Event-driven ERP system featuring React (Vite) dashboards, stateless Django REST APIs with JWT authentication, Django Signals for atomic inventory synchronization, and an embedded Groq (Llama 3.3) assistant with function calling.

* **[Sales ETL Pipeline with Apache Airflow & Streamlit](https://github.com/ALI22ASHAR/-Sales-Data-Pipeline-with-Airflow-Streamlit)**  
  Automated data engineering pipeline processing sales records via scheduled Airflow DAGs, paired with a Streamlit KPI analytics dashboard.

## 🚀 Running Locally

To view the portfolio locally, clone this repository and run any static file server:

```bash
# Clone the repository
git clone https://github.com/ALI22ASHAR/My-Portfolio.git
cd My-Portfolio

# Serve using Python 3
python -m http.server 3000
```

Open your browser and navigate to `http://localhost:3000/`.
